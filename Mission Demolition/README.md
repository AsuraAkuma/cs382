# Mission Demolition

Mission Demolition is a physics-based projectile puzzle game developed in Unity. The objective is to demolish structures and targets using a slingshot mechanism and various projectiles. The game features multiple levels, interactive environments, and engaging gameplay mechanics.

## Features

- **Physics-Based Gameplay:** Realistic 2D physics interactions using Unity's physics engine.
- **Slingshot Mechanic:** Drag and release to launch projectiles at targets.
- **Multiple Levels:** Progress through increasingly challenging stages.
- **Destructible Structures:** Knock down pillars, pigs, and other objects to complete objectives.
- **Custom Materials:** Physics materials for different object behaviors (e.g., BallPhys, PillarPhys).
- **Audio & Visuals:** Includes sound effects and visual assets for immersive gameplay.
- **Input System:** Supports Unity's Input System for flexible controls.
- **UI Elements:** Menus and in-game UI for navigation and feedback.

## Folder Structure

- `Assets/` - Main game assets, including prefabs, scripts, scenes, and resources.
  - `Levels/` - Level data and configurations.
  - `Scenes/` - Unity scene files.
  - `scripts/` - Game logic and mechanics scripts.
  - `UI/` - User interface assets.
- `Packages/` - Unity package dependencies.
- `ProjectSettings/` - Project configuration files.

## Getting Started

1. Clone the repository.
2. Open the project in Unity (recommended version: 2022.3 or later).
3. Open the main scene from `Assets/Scenes/`.
4. Play the game in the Unity Editor or build for your target platform.

## How to Play

- Use the mouse or touch to drag the slingshot and aim.
- Release to launch the projectile.
- Destroy all targets to complete the level.
- Progress to the next level for new challenges.
