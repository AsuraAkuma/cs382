
# Warehouse Tycoon

Warehouse Tycoon is a simulation and management game developed in Unity. Players build, expand, and manage a warehouse, optimizing logistics and resources to maximize profits. The project showcases simulation mechanics and Unity's UI capabilities.

## Features

- **Warehouse Management:** Build and upgrade warehouse facilities, manage inventory, and optimize logistics.
- **Resource System:** Track goods, finances, and staff to ensure efficient operations.
- **Custom Graphics:** Unique sprites and assets for warehouse items, staff, and environment.
- **Sound Effects & Music:** Audio feedback for actions and background music.
- **UI Elements:** Management dashboards, statistics, and menus using Unity UI Toolkit and TextMesh Pro.
- **Settings:** Adjustable game settings for gameplay and audio.

## Folder Structure

- `Assets/`: Game assets, including sprites, prefabs, scenes, scripts, audio, and UI.
- `Packages/`: Unity package dependencies.
- `ProjectSettings/`: Project configuration files.

## Getting Started

1. Open the project in Unity (recommended version: 2021.3 or later).
2. Open the main scene from `Assets/Scenes/`.
3. Play the game in the Unity Editor or build for your target platform.

## Functionality Overview

- Build and expand your warehouse.
- Manage inventory, staff, and finances.
- Optimize logistics for maximum efficiency and profit.
- Access settings to adjust gameplay and audio.

## Requirements

- Unity 2021.3 or later
- Windows, macOS, or Linux
