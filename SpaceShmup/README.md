
# SpaceShmup

SpaceShmup is a 2D space shooter game developed in Unity. Players control a spaceship, navigate through waves of enemies, and collect power-ups to survive and achieve high scores. The project demonstrates core concepts of shooter game development and Unity engine features.

## Features

- **Space Shooter Gameplay:** Control a spaceship, shoot enemies, and dodge incoming projectiles.
- **Enemy Waves:** Face increasingly difficult waves of enemy ships.
- **Power-Ups:** Collect power-ups to enhance firepower, shields, and abilities.
- **Custom Graphics:** Uses unique sprites for ships, projectiles, backgrounds, and effects.
- **Sound Effects & Music:** Includes audio for shooting, explosions, and background music.
- **UI Elements:** Score display, health bar, and menus using Unity UI Toolkit and TextMesh Pro.
- **Settings:** Adjustable game settings for difficulty and audio.

## Folder Structure

- `Assets/`: Game assets, including sprites, prefabs, scenes, scripts, audio, and UI.
- `Packages/`: Unity package dependencies.
- `ProjectSettings/`: Project configuration files.

## Getting Started

1. Open the project in Unity (recommended version: 2021.3 or later).
2. Open the main scene from `Assets/Scenes/`.
3. Play the game in the Unity Editor or build for your target platform.

## Functionality Overview

- Move the spaceship and shoot enemies.
- Collect power-ups to upgrade abilities.
- Survive as long as possible and achieve high scores.
- Access settings to adjust difficulty and audio.

## Requirements

- Unity 2021.3 or later
- Windows, macOS, or Linux
