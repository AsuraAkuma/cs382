# ApplePicker2D

ApplePicker2D is a 2D game project developed in Unity. The objective of the game is to catch falling apples using a movable bucket, providing a fun and interactive experience for players. The project is designed for educational purposes and demonstrates basic game development concepts in Unity.

## Features

- **Apple Catching Gameplay:** Apples fall from the top of the screen, and players must move the bucket to catch them.
- **Main Menu:** Includes a main menu with background graphics and interactive buttons.
- **Sound Effects:** Features sound effects for catching apples and other game events.
- **Player Data:** Stores player progress and scores in JSON files.
- **Custom Graphics:** Uses custom sprites for apples, buckets, buttons, and backgrounds.
- **Input System:** Supports keyboard and mouse input for controlling the bucket.
- **UI Elements:** Utilizes Unity's UI Toolkit and TextMesh Pro for polished user interfaces.
- **Settings:** Includes adjustable game settings and volume profiles.

## Folder Structure

- `Assets/`: Contains all game assets, including sprites, prefabs, scenes, scripts, audio, and UI elements.
- `PlayerData/`: Stores player data and scores in JSON format.
- `ProjectSettings/`: Unity project settings files.
- `Packages/`: Unity package manifest and lock files.

## Getting Started

1. Open the project in Unity (recommended version: 2021.3 or later).
2. Open the main scene from `Assets/Scenes/`.
3. Play the game in the Unity Editor or build for your target platform.

## Functionality Overview

- Move the bucket left and right to catch apples.
- Score points for each apple caught.
- Access settings and adjust volume or other preferences.
- View player progress and high scores.

## Requirements

- Unity 2021.3 or later
- Windows, macOS, or Linux
